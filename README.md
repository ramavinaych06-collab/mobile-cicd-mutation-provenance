# Mobile CI/CD Pipeline Optimization via Mutation Testing & Blockchain Provenance

## Overview
This project optimizes mobile application release engineering pipelines by integrating:
1. **AST-Based Selective Mutation Testing:** Evaluates test suite quality with reduced execution overhead.
2. **Blockchain-Based Software Provenance Tracking:** Logs immutable records of release artifacts (APK/AAB digests) and quality gate metrics.
3. **Defect Benchmark Validation Harness:** Evaluates the framework against real defect benchmarks (Defects4J / PROMISE paradigm).
